# US-004 — Configurar zonas, asientos y precios

**Estado:** ABSORBIDA EN US-003

Esta historia se elimina del alcance implementable. Zonas, mapas, importaciones y
múltiples precios aumentan el dominio sin aportar al objetivo inmediato de medir
concurrencia o TPS.

US-003 recibe un único precio `USD` y una capacidad, y genera entradas numeradas.
Si un experimento futuro demuestra que el tamaño o forma del inventario exige una
API separada, se abrirá una nueva historia basada en esa evidencia.
