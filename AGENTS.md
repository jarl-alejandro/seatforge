# SeatForge contributor rules

## Contract-first HTTP APIs

- `docs/api/openapi.yaml` is the canonical HTTP contract.
- When implementing a new API operation, use the HTTP interface and DTOs generated by the existing OpenAPI/Swagger Gradle configuration. Do not duplicate request/response DTOs or declare a parallel controller mapping.
- Keep generated code under `seatforgemain/build/generated/openapi`; never edit generated files manually.
- Keep OpenAPI types at the HTTP adapter boundary. Domain models, application commands, ports, use cases, and persistence models remain handwritten.

## Tests

- Every implementation or behavior change must include unit tests.
- Add integration tests when behavior crosses HTTP, persistence, transactions, security, or module boundaries.
